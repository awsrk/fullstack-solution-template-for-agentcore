# Frontend Development Guide

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS for styling
- shadcn/ui for components (configured via `frontend/components.json`)
- Hosted on AWS Amplify

## Key Conventions

### Component Library

Always use existing shadcn/ui components from `frontend/src/components/ui/` before writing custom ones. Add new shadcn components via:

```bash
npx shadcn@latest add <component-name>
```

Never manually create files in `frontend/src/components/ui/` — let the CLI manage them.

### TypeScript

Use explicit types everywhere. Shared types for chat/streaming live in `frontend/src/components/chat/types.ts`. Add new shared types there rather than inlining them.

### Auth

Authentication is handled by `frontend/src/components/auth/AuthProvider.tsx` and `frontend/src/lib/auth.ts` using Cognito OIDC. Do not bypass or duplicate auth logic. Use the `useAuth` hook from `frontend/src/hooks/useAuth.ts` to access auth state.

### AgentCore Streaming Client

The streaming client lives in `frontend/src/lib/agentcore-client/`. It handles SSE parsing and routes events to the correct parser based on the agent pattern. Before modifying streaming behavior:

1. Read `docs/STREAMING.md` — it explains the full event flow
2. Parsers are in `frontend/src/lib/agentcore-client/parsers/` — one per agent pattern
3. Register new parsers in `frontend/src/lib/agentcore-client/client.ts`

### Adding a New Agent Pattern Parser

1. Create `frontend/src/lib/agentcore-client/parsers/my-pattern.ts` exporting a `ChunkParser`
2. Register it in `client.ts`
3. Set `pattern: my-pattern` in `infra-cdk/config.yaml`

## Configuration

`frontend/public/aws-exports.json` is auto-generated by `scripts/deploy-frontend.py` from CDK stack outputs. Never edit it manually — it gets overwritten on every deploy.

## Running Locally

Frontend requires a deployed AWS stack. Use Docker Compose from the `docker/` directory:

```bash
export MEMORY_ID=your-memory-id
export STACK_NAME=your-stack-name
export AWS_DEFAULT_REGION=us-east-1
cd docker
docker-compose up --build
```

See `docs/LOCAL_DEVELOPMENT.md` for full setup instructions.

## Linting

```bash
cd frontend && npm run lint
```

This is also run as part of `make lint` from the repo root.
